# Vani Raj portfolio


Static site. Open `index.html` to view it. Text lives in `index.html`; videos and images are in `assets/`.

## Publish with GitHub Pages
1. Create a new public repository on GitHub.
2. Upload everything in this folder (including the `assets` folder and `.nojekyll`).
3. Go to Settings, then Pages. Under Build and deployment, choose "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. After a minute the site is live at https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
